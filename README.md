# 地区高中学业情况看板

这是“项目问题”的网页实现。页面面向普通读者，将信息分成五个可点击栏目：地区总览、成绩表现、学校比较、选科比例和数据说明。

## 页面怎么使用

打开网页后，点击页面顶部的栏目卡片即可切换：

1. **地区总览**：查看覆盖学校、E8 参考人数、三门主科平均分、历次考试规模和主要选科组合；
2. **成绩表现**：选择学校、考试和科目，查看平均分、成绩中点、中间 50% 成绩区间、成绩分布及历次平均分；
3. **学校比较**：固定一场考试和一门科目，查看各校平均分排序和学校统计明细；
4. **选科比例**：查看地区整体或单所学校的选科组合饼图、六门选考科目选择率和组合明细；
5. **数据说明**：查看成绩趋势、总分口径、学校比较和选科统计的解释。

页面不再使用“平均标准分”。跨考试部分展示原始平均分，并明确提示不同试卷难度可能影响结果。E1、E2 的总分科目构成与后续考试不同，因此总分趋势从 E3 开始。

## 文件结构

```text
项目问题/
├─ index.html                 网页入口与五个栏目
├─ preprocess_data.py         从 E1—E8 生成网页汇总数据
├─ css/style.css              页面布局与响应式样式
├─ js/app.js                  栏目切换、筛选、解读和图表逻辑
└─ data/dashboard_data.json   自动生成的学校层级汇总数据
```

## 本地运行

在 PowerShell 中进入“材料”目录，然后依次运行：

```powershell
python .\项目问题\preprocess_data.py
python -m http.server 8000 --directory .\项目问题
```

看到 `Serving HTTP on ... port 8000` 后，不要关闭该窗口。在浏览器中打开：

```text
http://localhost:8000
```

结束查看时回到 PowerShell，按 `Ctrl + C` 停止服务。

不要直接双击 `index.html`，因为浏览器通常会限制网页直接读取本地 JSON 数据。

## 数据更新

如果 E1—E8 原始 Excel 文件发生变化，只需重新运行：

```powershell
python .\项目问题\preprocess_data.py
```

脚本会重新生成 `data/dashboard_data.json`。刷新浏览器后即可看到新结果。

## 数据与统计口径

- “总分”使用 `总分_原始分`，其他科目使用对应的单科原始成绩；
- “成绩中点”指中位数；
- “中间 50% 成绩区间”指第 25 百分位至第 75 百分位；
- 选科比例以 E8 高三二模实际参加的三门选考科目组合确定；
- 学校排序是同一考试、同一科目的描述性结果，不能单独解释为学校教学质量；
- 网页数据只保留地区和学校层级的汇总统计，不包含姓名、考号或单个学生成绩记录。
