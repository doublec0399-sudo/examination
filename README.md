# 地区高中学业情况

将信息分成五个可点击栏目：地区总览、成绩表现、学校比较、选科比例和数据说明。
为保护隐私 抹去学生姓名 考号 单个考试成绩


## 文件结构

```text
项目问题/
├─ index.html                 网页入口与五个栏目
├─ preprocess_data.py         从 E1—E8 生成网页汇总数据
├─ css/style.css              页面布局与响应式样式
├─ js/app.js                  栏目切换、筛选、解读和图表逻辑
└─ data/dashboard_data.json   学校层级汇总数据
```
